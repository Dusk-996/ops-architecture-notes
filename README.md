# 网站架构与运维排障图解

八篇中文实战讲义，从一次网站请求出发，追踪它在哪层被转发、缓存或阻塞。每篇开头都有可直接在 GitHub 阅读的架构图，随后给出原图勘误、验证命令和观察结果的方法。原始课程图和核验依据列在各篇文末。
